À propos de DataDex

Application web pédagogique développée en Go avec l'API Plaid Sandbox.

Comment ça marche ?

DataDex récupère des transactions bancaires simulées depuis l'environnement Plaid Sandbox via une API HTTP en Go (librairie standard), sans JavaScript côté client.

  • Recherche & filtres : recherche par texte, catégorie, statut ou montant minimum.
  • Pagination : navigation par page avec choix de 10, 20 ou 30 éléments.
  • Favoris persistants : sauvegarde des transactions sélectionnées dans un fichier JSON local.
  • Sécurité : les identifiants Plaid passent uniquement par des variables d'environnement.
